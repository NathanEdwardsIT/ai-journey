# My Machine Learning Journey

**Started: October 18, 2026**

## About This Project

This repository documents my journey into Artificial Intelligence and Machine Learning, starting with the fundamentals and progressively working toward advanced AI research.

Coming from a software development background, I'm expanding my knowledge of mathematics, data science, machine learning, and neural networks to better understand how modern AI systems actually work.

## My Goal

My long-term ambition is to become an **AI Research Engineer**, ideally contributing to research at organizations like OpenAI or Anthropic.

I'm particularly interested in **mechanistic interpretability, neural networks, large language models, and AI alignment** — understanding how models learn, represent information, and develop complex behaviors.

## What You'll Find Here

This repository will serve as a record of my progress, including:

- Coursework and programming exercises
- Python, pandas, NumPy, and PyTorch experiments
- Machine learning algorithms implemented from scratch
- Neural network and transformer projects
- Research paper reproductions and interpretability experiments

**The ultimate goal is to progress from learning how to use AI to understanding how it works — and eventually contributing to its development.**
